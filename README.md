# SE_POS_System
- A simple menu based POS system.
- Uses an interface similar to my Monster and Wordle Games.
- It isn't that complex because I didn't have much time to make this. Just spent one day on this.

## Table of Contents

## Tools
- C++

## Features
- Can record orders.
- Can refresh inventory.
- Can view orders.
- Can check inventory.
- It is recommended to read the basic documentation I had to make.
- Two files are bundled: Items and Orders.
- Keyboard based menu that is made possible by using circular arrays.
